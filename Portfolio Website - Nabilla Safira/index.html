Tentang

Saya memiliki latar belakang Teknik Informatika dan pengalaman kerja di bidang administrasi keuangan. Saat ini saya sedang membangun karier di Software Quality Assurance melalui QA bootcamp dan personal projects. Saya memiliki pengalaman dalam manual testing, functional testing, test case design, test execution, bug reporting, API testing menggunakan Postman, serta validasi data menggunakan SQL dan MySQL. Saya juga memiliki exposure terhadap automation testing menggunakan Cypress dan Appium.

Pengalaman saya di bidang administrasi membantu membangun ketelitian dalam data verification, dokumentasi, dan reporting — kemampuan yang saya terapkan dalam proses software testing.
